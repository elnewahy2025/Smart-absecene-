# DEPLOYMENT
**Dev:** `npm ci`; copy `.env.example`→`.env`; `npm run dev` (tsx watch `server.ts` + Vite middleware, port 5050). Emulator mode: `npm run emulators`, `seed:emulator`, `dev:emulator`, `smoke:emulator`.
**Build:** `npm run build` = `vite build` (→ `dist/`) + `esbuild server.ts → server.js` (ESM, node20, packages external). **Start:** `node server.js` (`NODE_ENV=production` serves `dist/`).
**Render:** `render.yaml` (web, Docker, free plan, health `/api/health`, autoDeploy). Dockerfile: Node 22-bookworm-slim two-stage; runtime installs Chromium + fonts, `npm ci --omit=dev`, copies `dist`, `server.js`, `src/config`; runs as user `node`; `EXPOSE 5050`; Vite `VITE_*` baked at build via ARG/ENV.
**Vercel:** `vercel.json` (`npm run build`, output `dist`, function `api/handler.ts` 1024 MB/60 s, rewrite `/api/*`→handler, security headers). Handler imports `../server.js` (needs build output). Chromium via `@sparticuz/chromium`.
**Database requirements:** Firebase project with Auth (email/password) and Firestore; deploy `firestore.rules` + `firestore.indexes.json` (`firebase.json`). **Migrations:** none. **Seeding:** `seed-firebase-auth.ts`, `seed-emulator.mjs`, `seed-tenant-demo.mjs`, `seed-demo-roles.mjs`; claims: `backfill-user-claims.mjs`; owner: `grant-platform-owner.mjs`; secrets: `migrate-ai-secrets-to-firestore.mjs`, `rotate-tenant-ai-secrets.mjs`; preflight `golive-check.mjs` (not run).
**CI:** one workflow `ci-security-audit.yml` (checkout pinned by SHA, Node 20, `npm install` (not `ci`), `npm run lint`, secret scan, `.env` presence check, `.env.example` check, build, tests) — **no deploy job; tests fail without master key (QA-01)**.
**Runtime assumptions:** writable FS optional (JSON mirror, secrets file fall back), Chromium available, Firebase Admin credential (`FIREBASE_SERVICE_ACCOUNT_BASE64` etc.) mandatory for API auth, `TENANT_ENCRYPTION_MASTER_KEY` mandatory for AI keys, free Render plan sleeps/ephemeral FS (secrets then rely on Firestore store).
