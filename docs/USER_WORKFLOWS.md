# User Workflows

## Staff workflow

1. Open the dashboard and select the active tenant.
2. Review attendance sessions and mark students as present, absent, late, or excused.
3. Submit or reopen a session as needed.
4. Review incoming justifications and medical excuses.
5. Send reminders or formal warnings to guardians.
6. Generate a daily digest summary for school leadership.
7. Export reports for official archive or compliance use.

## Parent workflow

1. Parent logs in and sees only their children.
2. Parent receives attendance notices and warning messages.
3. Parent can submit a medical excuse or justification against a specific absence.
4. Parent receives AI-reviewed outcome and can follow up with school staff.

## Attendance review workflow

1. A teacher creates or updates a session.
2. The student status is recorded per session.
3. The school can approve, reject, or refer a justification.
4. The attendance summary updates automatically.

## Daily digest workflow

1. A compliance or admin user triggers digest generation.
2. The system calculates anomalies, high-risk students, and pending justifications.
3. A Gemini-based summary may be appended.
4. The digest can be dispatched to recipients.
